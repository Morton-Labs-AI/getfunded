# Support

## Where to ask

- **Questions and ideas:**
  [GitHub Discussions](https://github.com/Morton-Labs-AI/getfunded/discussions)
- **Bugs:** open an issue with the bug report template
- **Wrong data about a funder:** open an issue with the data correction
  template
- **Security problems:** see [SECURITY.md](SECURITY.md). Do not post them
  publicly.

## Hosted service vs self-install

| | getfunded.ai (hosted) | Self-install |
|---|---|---|
| Who runs it | Morton Labs | You |
| Data | Loaded and refreshed for you | You run the corpus pipeline |
| Updates | Automatic | You pull and redeploy |
| Support | Email support for account holders | Community support in Discussions |
| Cost | See getfunded.ai for plans | Free (your own hosting costs apply) |

Hosted-service questions: support@getfunded.ai.

## No SLA

The open-source project has no service-level agreement. Maintainers answer
when they can. Nobody is on call. If you need guaranteed response times,
use the hosted service.
